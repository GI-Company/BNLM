BNLM

A small decoder-only Transformer, trained from random initialization and run entirely client-side — JavaScript + WebGPU (WGSL), no server, no Python. See DESIGN.md for the architecture writeup.

1. Training text

Separate stories/documents with a blank line (or <|endoftext|>, the real TinyStories dump's separator). Training windows are sampled from within a single story and never cross into the next one — see DESIGN.md.

"linear" trades softmax attention for causal linear attention — generation then runs on a recurrent O(1)-memory-per-token path instead of re-scanning the context window each step. See DESIGN.md's "v2" section.
